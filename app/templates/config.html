Como ligar o Resend

Para começar hoje, sem domínio:

  1. Cole a API Key do Resend no campo ao lado.
  2. Use {{ cfg.remetente_teste }} como remetente.
  3. Em Enviar teste, mande para o mesmo e-mail com que você criou a conta no Resend. Só ele aceita mensagens nesse modo.

Para valer, com domínio próprio:

  1. No Resend, em Domains, adicione um domínio que seja seu (ex.: xmljats.com.br).
  2. Publique no DNS os registros que ele mostrar (SPF, DKIM e, se pedir, DMARC).
  3. Espere ficar "verified" e troque o remetente para nao-responda@seudominio.com.br.

O endereço do Dokploy (.sslip.io) não serve: ele não é um domínio seu e não dá para publicar DNS nele. O endereço do site pode continuar sendo esse; só o remetente precisa de domínio verificado.
